NVIDIA publica una arquitectura OpenShell para controlar agentes empresariales

El diseño combina aislamiento, seguimiento de acciones y políticas aplicadas durante la ejecución.

Fuente original · Breve

Noticias IA
Fuente: 21 oct 2026

Ilustración editorial. No representa una captura del producto.

La arquitectura de referencia OpenShell, anunciada el 21 de octubre, coordina infraestructura Vera Rubin para modelos, CPU Vera para herramientas y BlueField-4 con Sentry para aplicar políticas.

NVIDIA la presenta como una base para desplegar agentes en centros de datos y equipos locales. El software OpenShell actúa como límite de ejecución; las integraciones permiten observar acciones y restringir accesos.

La arquitectura está documentada y disponible, según el anuncio. Esto no certifica la seguridad de cualquier instalación ni sustituye las pruebas de aislamiento y permisos.
