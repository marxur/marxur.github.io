Tencent presenta Hy Memory 2.0 para conectar la memoria de los agentes

Tencent presenta una pila de memoria con tres piezas separables: el modelo especializado Hy-Memory-30B-A3B, el framework Hy Memory y la aplicación MemHub.

Fuente original · Breve

Noticias IA
Fuente: 16 oct 2026

Ilustración editorial. No representa una captura del producto.

Tencent presenta una pila de memoria con tres piezas separables: el modelo especializado Hy-Memory-30B-A3B, el framework Hy Memory y la aplicación MemHub. El sitio del proveedor fecha el anuncio el 16; el preprint del modelo se presentó el 15. Se verifican código, paquete Python y un listado de archivos de pesos, sin instalarlos. La evaluación publicada usa subconjuntos fijos del 20 % de sus pruebas y no demuestra superioridad general sobre Claude. La propuesta busca continuidad entre herramientas; la compatibilidad de MemHub debe comprobarse por separado.

Lo que cambia para ti.

Estudiar integración antes de adoptar.

El matiz que importa.
No hemos realizado una prueba independiente. Rendimiento de autores, no reproducido. El SDK puede usar servicios LLM y embeddings externos: local-first no equivale a todo local. Compatibilidad y binarios de MemHub sin probar.
